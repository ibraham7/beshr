# beshr — Beshr Kashkoush portfolio

موقع أعمال لمصمم الجرافيك بشر قشقوش مع لوحة تحكم كاملة. ألوان الموقع مأخوذة من الشعار (`#1e5060` · `#c4e3c2` · `#8da58f`).

## التشغيل

```bash
node server.js        # http://localhost:3000
```

لا يحتاج أي مكتبات (Node 18+ فقط).

- الموقع: `/`
- لوحة التحكم: `/admin` — كلمة المرور الافتراضية `beshr@2026` (غيّرها فوراً من تبويب **الأمان**، أو شغّل بمتغير `ADMIN_PASSWORD`).

## لوحة التحكم

تعديل كل نص (عربي/إنجليزي)، الشعارات، الصور، الألوان، ترتيب وإظهار الأقسام، الخدمات، الأعمال (مع معرض صور لكل عمل)، التصنيفات، بيانات التواصل، ورسائل الزوار — مع معاينة حية ومكتبة وسائط. `Ctrl+S` للحفظ.

## البيانات والحفظ

كل ما يعدّله صاحب الموقع (المحتوى، كلمة المرور، رسائل الزوار، الصور المرفوعة) يُحفظ في قاعدة بيانات **Supabase** (مشروع `beshr database`)، لذلك لا يضيع شيء عند إعادة تشغيل الاستضافة المجانية.

| متغير | الوصف |
| --- | --- |
| `SUPABASE_URL` | رابط مشروع Supabase |
| `SUPABASE_SERVICE_KEY` | المفتاح السري (Project Settings ← API Keys ← secret). **لا يوضع في الكود أبداً.** |
| `ADMIN_PASSWORD` | كلمة المرور الأولية (تُستخدم عند أول تشغيل فقط) |
| `PORT` | المنفذ (افتراضي 3000) |

بدون متغيرَي Supabase يعمل السيرفر محلياً ويحفظ في مجلد `data/` (للتطوير فقط).

الجداول في Supabase: `site_kv` (المحتوى وكلمة المرور)، `content_history` (آخر 30 نسخة قبل كل حفظ)، `messages`، ومخزن الصور `uploads`. كل الجداول مقفلة (RLS) ولا يصل إليها إلا السيرفر بالمفتاح السري.

المحتوى الافتراضي في `content.default.json`، وصور الأعمال التجريبية تُولَّد بـ `npm run covers`.

## النشر

الموقع على Render (`render.yaml`). أي دفع إلى `main` يُنشر تلقائياً. أضف `SUPABASE_URL` و`SUPABASE_SERVICE_KEY` من لوحة Render ← Environment.
